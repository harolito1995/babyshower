# 🌸 Project Mariapaz

> "Una experiencia web cinematográfica inspirada en la magia de los cuentos."

---

## Visión

Project Mariapaz no es una invitación digital convencional.

Es una experiencia inmersiva diseñada para emocionar a cada invitado desde el primer segundo.

La página contará una historia utilizando ilustraciones, animaciones, sonido y una narrativa inspirada en los cuentos clásicos y la magia de Disney, pero con una identidad visual completamente original.

Nuestro objetivo no es mostrar información.

Nuestro objetivo es transmitir emociones.

Cada sección debe sentirse como un nuevo capítulo.

Cada animación debe tener un propósito.

Cada transición debe ser delicada.

Cada color debe transmitir tranquilidad, amor y esperanza.

---

## Filosofía

Menos elementos.

Más emoción.

Menos texto.

Más narrativa.

Menos efectos.

Más magia.
